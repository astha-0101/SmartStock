# SmartStock – Intelligent Inventory Management System


SmartStock is a simple inventory management system frontend developed using HTML and CSS.

The project provides a basic interface to view inventory information and add new products. Currently, the project is a frontend prototype and uses static sample data.

## Features

- Inventory Dashboard
- View total products and stock information
- View low-stock products
- View product details in a table
- Add Product form
- Product category selection
- Responsive layout for smaller screens
- Simple navigation between pages

## Pages

### 1. Dashboard

The Dashboard displays:

- Total Products
- Low Stock count
- Total Stock Units
- Inventory Overview
- Product name
- Category
- Price
- Quantity
- Reorder Level
- Stock Status
- Stock Information

### 2. Add Product

The Add Product page contains a form for entering:

- Product Name
- Category
- Price
- Quantity
- Reorder Level
- Supplier
