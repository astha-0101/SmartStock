# SmartStock – Intelligent Inventory Management System

SmartStock is a web-based inventory management system designed to help businesses manage products, inventory, orders, and suppliers efficiently.

The project is being developed in multiple phases. This repository currently contains the **frontend prototype built using HTML5 and CSS3**.

## Current Phase

### Phase 1 – HTML & CSS Frontend

The current version focuses only on designing and structuring the user interface.

No JavaScript, React, Spring Boot, database, or machine learning has been implemented yet.

## Pages

The current frontend contains the following pages:

- Dashboard
- Products
- Add Product
- Inventory
- Orders
- Suppliers
- Demand Forecast
